# 자비스 폰 앱 (JarvisPhoneApp) 설치/사용 설명서

이 폴더는 **안드로이드 스튜디오 프로젝트**예요. PC의 "AI 에이전트 오피스"
프로그램과는 완전히 별개의 앱이고, PC 프로그램의 **"📶 폰 연동 서버"**를
켜둔 상태에서 같은 Wi-Fi 안에서 서로 통신해요.

## 왜 이 앱이 필요한가요?

PC 프로그램 혼자서는 폰 화면을 볼 수도, 누를 수도 없어요. 그래서
"음성으로 내비게이션 켜줘", "카카오톡에서 메시지 보내줘" 같은 요청을
**폰에서** 실제로 실행해줄 작은 앱이 따로 필요해요. 이 앱이 음성을
듣고 → PC에게 "이걸 하려면 어떻게 해야 할지" 물어보고 → PC가 알려준
계획대로 폰에서 실행하는 역할을 해요.

## 1. 준비물

- **Android Studio** (무료, 이 PC가 아니라 **직접 쓰시는 컴퓨터**에
  설치돼 있어야 해요 — 다운로드: developer.android.com/studio)
- 안드로이드 폰 (8.0 이상)
- PC와 폰이 **같은 Wi-Fi(같은 공유기)**에 연결돼 있을 것

> ⚠️ 이 프로젝트는 레인보우컴퓨터 PC 프로그램을 만든 샌드박스 환경에서
> 작성됐는데, 그 환경은 구글 서버에 접속할 수 없어서(네트워크 제한)
> 실제로 빌드해서 기기에 설치해보는 **실기기 테스트를 하지 못했어요**.
> 코드는 공식 안드로이드 API 문서를 기준으로 꼼꼼히 작성했지만, 처음
> 빌드/실행할 때 사소한 오류가 나올 수 있다는 점을 미리 말씀드려요 —
> 오류 메시지를 알려주시면 바로 고쳐드릴게요.

## 2. 빌드 & 설치

1. Android Studio를 열고 "Open" → 이 `jarvis_android` 폴더를 선택해요.
2. 처음 열면 Gradle이 필요한 구성요소를 자동으로 내려받아요(인터넷
   필요, 몇 분 걸릴 수 있어요). 완료될 때까지 기다려주세요.
3. 폰을 USB로 연결하고 폰에서 "USB 디버깅"을 켜요(설정 > 휴대전화
   정보 > 빌드 번호를 7번 눌러 "개발자 옵션"을 켠 뒤, 개발자 옵션에서
   "USB 디버깅" 켜기).
4. Android Studio 상단의 ▶️(Run) 버튼을 누르면 폰에 바로 설치/실행돼요.
   (USB 연결이 번거로우면 Build → Generate Signed/Unsigned APK로 APK
   파일을 만들어서 카카오톡/이메일 등으로 폰에 보내 설치해도 돼요 —
   이 경우 폰에서 "출처를 알 수 없는 앱 설치 허용"을 한 번 켜야 해요.)

## 3. 첫 실행 — PC와 연결하기

1. PC 프로그램에서 "🔗 연동 · 알림" → "📶 폰 연동 서버"를 켜요.
2. PC 화면에 표시되는 **IP 주소 / 포트 / 인증 토큰**을 확인해요.
3. 폰 앱을 열고 "PC 연결 설정"에 그 값을 그대로 입력한 뒤 "저장하고
   연결 확인"을 눌러요. "연결 성공!"이 뜨면 준비 끝이에요.
4. PC에서 HTTPS(암호화)를 켜뒀다면 폰 앱의 "PC에서 HTTPS를 켜뒀어요"
   체크박스도 같이 켜주세요.

## 4. 기본 사용법

"🎙️ 눌러서 말하기" 버튼을 누르고 말하면 끝이에요. 예시:

- "스타벅스 둔산점으로 길안내해줘" → 지도 앱으로 바로 길안내 시작
- "카카오톡 열어줘" → 카카오톡 실행
- "오늘 일정 알려줘" / "오늘 날씨 어때" 같은 일반 질문도 그대로 물어볼
  수 있어요(PC 프로그램에 이미 있는 기능을 그대로 씀).

처음 실행하면 마이크 권한과 알림 권한을 허용해달라는 창이 떠요 — 둘 다
허용해주세요(마이크는 음성 인식에, 알림은 아래 "항상 대기" 기능에
필요해요).

## 5. "항상 대기" 알림 (선택)

진짜 "헤이 빅스비"처럼 24시간 듣고 있는 기능은 배터리/사생활 부담이
커서 일부러 넣지 않았어요. 대신 "항상 대기 알림 켜기"를 켜두면 알림이
하나 떠 있고, 그 알림의 "🎙️ 말하기"를 누르면 앱을 열지 않고도 바로
말할 수 있어요.

## 5-1. 호출어로 부르기 (베타, 완전 오프라인)

"자비스야" 처럼 **원하는 이름을 부르면 자동으로 듣기 시작**하는 기능이에요.
앞서 설명한 "항상 대기 알림"과 달리 알림을 직접 누를 필요 없이 그냥 말로
부르기만 하면 돼요. 호출어는 앱 화면에서 **본인이 원하는 어떤 이름으로든
바꿀 수 있어요**(기본값 "자비스").

**동작 방식(중요)**: 인터넷에 있는 구글 같은 서버로 음성을 보내는 게
아니라, **Vosk**라는 오픈소스 음성인식 엔진을 폰 안에 내려받아서 완전히
오프라인으로 "방금 그 말이 호출어인지"만 계속 확인해요. 그래서:

- 호출어를 듣고 있는 동안은 녹음 내용이 PC나 외부 서버로 전송되지 않아요
  (정말로 호출어가 인식됐을 때만, 그 다음 명령을 기존 방식대로 안드로이드
  음성인식으로 듣고 PC에 보내요).
- 인터넷 없이도 호출어 인식 자체는 계속 동작해요(최초 모델 다운로드만
  인터넷이 필요).

**사용 방법**:

1. 앱 화면의 "호출어로 부르기" 섹션에서 원하는 이름을 입력하고 "호출어
   저장"을 눌러요.
2. "음성 인식 모델 다운로드" 버튼을 눌러요(약 80MB, **Wi-Fi 권장** — 모바일
   데이터로 받으면 데이터가 많이 소모될 수 있어요). 다운로드가 끝나면
   "✅ 모델 준비 완료"라고 표시돼요.
3. "호출어 상시 대기 켜기" 스위치를 켜요. 알림이 하나 뜨고, 그 뒤로는 그냥
   "(호출어)야, 오늘 날씨 어때?" 처럼 말을 걸면 돼요.

**솔직한 한계**:

- 이 기능은 **실기기에서 테스트해보지 못한 상태로 만들어졌어요**(앞서
  설명한 샌드박스 환경 제약 때문에 다른 부분보다도 특히 이 부분은 오디오를
  실시간으로 계속 처리하는 코드라 실제 기기에서만 드러나는 문제가 있을
  가능성이 더 높아요). 안 불리거나, 엉뚱한 타이밍에 반응하거나, 호출어 대기
  → 명령 듣기로 전환되는 체감이 어색할 수 있어요 — 증상을 알려주시면
  조정해드릴게요.
- 지금 쓰는 음성 모델은 **한국어 전용 소형 모델**이에요. "Jarvis"처럼 영어
  이름을 넣으면 한국어 발음(자비스처럼)으로는 인식될 수 있지만, 영어
  발음 그대로는 잘 안 맞을 수 있어요. 가능하면 한글로 2음절 이상의, 일상
  대화에 잘 안 나오는 독특한 이름을 추천해요(예: "자비스", "레인보우"는
  괜찮고, "어", "네" 같은 짧고 흔한 말은 오작동이 잦을 수 있어요).
- 상시 듣기 때문에 "항상 대기 알림"보다 배터리를 조금 더 써요. 체감상
  부담스러우면 꺼두고 기존 "항상 대기 알림"(알림 탭 한 번) 방식을 쓰는 게
  나을 수 있어요.
- 모델 출처: [Vosk 공식 모델 저장소](https://alphacephei.com/vosk/models)의
  `vosk-model-small-ko-0.22`(Apache-2.0 라이선스).

## 6. "다른 앱도 직접 조작" (Bixby 스타일, 선택 — 강력한 권한)

"카카오톡에서 OOO에게 메시지 보내줘"처럼 **앱 안의 화면을 대신 눌러야
하는** 요청은 안드로이드의 "접근성(Accessibility)" 권한이 있어야
동작해요.

1. 폰 앱의 "접근성 설정 열기" 버튼을 눌러요(또는 폰 설정 > 접근성 >
   설치된 앱 > "자비스"로 직접 이동해도 돼요).
2. 목록에서 "자비스"를 찾아 켜요. 안드로이드가 "이 앱이 화면 내용을
   읽고 사용자 대신 동작을 수행할 수 있다"는 강한 경고를 보여줄 거예요
   — **본인이 설정한 본인 폰에서만** 켜주세요. 이 권한은 매우 강력해서
   안드로이드가 앱 스스로 켜지 못하게 막아뒀기 때문에 반드시 수동으로
   켜야 해요.
3. 켜고 나면 폰 앱 화면에 "✅ 접근성 권한이 켜져 있어요"라고 표시돼요.

**이 기능의 솔직한 한계**: PC는 사용자의 실제 폰 화면을 본 적이
없어요. "카카오톡에 보통 이런 화면/버튼이 있을 것"이라는 AI의 일반적인
지식으로 조작 순서를 추측해서 만들기 때문에, 카카오톡이 업데이트됐거나
화면 구성이 다르면 실패할 수 있어요. 실패하면 "N번째 단계에서
멈췄어요"라고 알려주고 멈추도록 만들어뒀어요(끝까지 억지로 진행해서
엉뚱한 곳을 누르거나 엉뚱한 내용을 전송하지 않도록 하기 위함). 자주
쓰는 동작이 계속 실패하면 말씀해주세요 — 단계를 더 구체적으로
다듬거나, 그 앱 전용 단계를 따로 만들어드릴 수 있어요.

## 7. 내비게이션은 어떤 앱으로 열리나요?

설치된 앱 중 다음 우선순위로 자동 선택해요: 구글맵 → 네이버지도 →
카카오맵 → 티맵 → (그래도 없으면) 폰의 기본 지도 앱. 구글맵은 공식
문서에 나온 안정적인 방식(`google.navigation:q=`)을 쓰고, 네이버지도/
카카오맵/티맵은 각 서비스의 공개된 URL 방식을 썼지만 **실기기로
검증하지 못했어요** — 원하는 앱으로 안 열리면 알려주세요.

## 8. 자주 묻는 문제

**"연결 실패"가 떠요** → PC와 폰이 같은 Wi-Fi인지, PC에서 "폰 연동
서버"를 켰는지, IP/포트/토큰을 정확히 입력했는지 확인해주세요. 공유기에
따라 "AP 격리(클라이언트 격리)" 기능이 켜져 있으면 같은 Wi-Fi라도 기기끼리
통신이 안 될 수 있어요 — 공유기 설정에서 그 기능을 꺼야 할 수도 있어요.

**내비게이션이 원하는 앱으로 안 열려요** → `NavigationLauncher.kt`의
우선순위나 URL 스킴을 조정해야 할 수 있어요. 어떤 앱으로 열리길
원하는지 알려주시면 수정해드릴게요.

**앱 조작(Bixby 기능)이 자꾸 실패해요** → 위 6번 항목의 한계 설명을
참고해주세요. "몇 번째 단계에서 멈췄는지" 알려주시면 그 단계를
구체적으로 고쳐드릴 수 있어요.

**호출어를 불러도 반응이 없어요** → ① 모델을 다운로드했는지("✅ 모델
준비 완료" 표시) ② "호출어 상시 대기" 스위치가 켜져 있는지 ③ 호출어가
너무 짧거나 흔한 말은 아닌지 확인해주세요. 그래도 안 되면 호출어를 더
또렷하고 독특한 한글 단어로 바꿔보세요.

**호출어가 아닌 말에도 자꾸 반응해요(오작동)** → 짧거나 흔한 발음의
호출어일수록 오작동이 잦아요. 2음절 이상의, 평소 대화에 잘 안 나오는
단어로 바꿔서 "호출어 저장"을 다시 눌러주세요.

**플레이스토어에는 못 올리나요?** → 이 앱은 "다른 앱 화면을 자동으로
조작"하는 용도로 접근성 권한을 쓰고, 설치된 앱 전체 목록도 들여다보기
때문에, 두 가지 다 플레이스토어 심사 정책상 일반적인 배포용 앱으로는
허용되지 않아요. 이 앱은 처음부터 "본인이 직접 설치해서 쓰는 개인용
도구"로 설계됐어요.

## 9. 보안 참고

- 인증 토큰은 PC 프로그램이 자동으로 만들어주는 값이에요. 이 토큰을
  아는 사람만 PC에 명령을 보낼 수 있으니, 남에게 알려주지 마세요.
- PC에서 HTTPS를 켜면 자체 서명 인증서를 쓰는데, 이 폰 앱은 "같은 집
  Wi-Fi에서만 쓰는 개인용 도구"라는 전제로 그 인증서를 별도 검증 없이
  신뢰해요. 더 엄격하게 하고 싶으면(예: 외부인이 접근할 수 있는
  네트워크 환경이라면) PC가 내보낸 인증서 파일을 폰에 복사해서 정확히
  그 인증서만 신뢰하도록(인증서 핀닝) 바꿀 수 있어요 — 필요하시면
  말씀해주세요.
